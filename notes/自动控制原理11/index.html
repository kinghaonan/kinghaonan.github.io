5.3.1 频域稳定性分析概述

稳定性回顾

线性系统的稳定性由传递函数的极点决定：

  • 开环特征多项式：D(s)D(s)D(s)
  • 闭环特征多项式：D(s)+N(s)D(s) + N(s)D(s)+N(s)
  • 闭环传递函数：T(s)=G(s)1+G(s)T(s) = \frac{G(s)}{1 + G(s)}T(s)=1+G(s)G(s)​
  • 开环（回路）传递函数：L(s)=G(s)L(s) = G(s)L(s)=G(s)

稳定性分析的基本问题

已知开环极点分布，如何利用开环频率特性判断闭环极点分布？

相角增量概念

考虑复平面左右不同极点/零点位置相角的变化量：

  • 左半平面极/零点：ΔP=π\Delta P = \piΔP=π
  • 右半平面极/零点：ΔP=−π\Delta P = -\piΔP=−π

  • 相对于曲线外部某点的相角变化为0
  • 相对于闭合曲线内部的点，顺时针为−2π-2\pi−2π，逆时针为2π2\pi2π

5.3.3 对数频率稳定判据

对数频率稳定判据的基本原理

对数频率稳定判据：若开环系统为最小相位的稳定系统，其伯德图满足如下条件之一，则闭环系统稳定：

  1. 在幅值穿越频率时，系统相角大于−180∘-180^\circ−180∘
  2. 在相角穿越频率时，系统幅值小于1（0 dB）
  3. 系统的幅值穿越频率小于相角穿越频率

关键概念

  • 幅值穿越频率 ωc\omega_cωc​：A(ωc)=1A(\omega_c) = 1A(ωc​)=1（0 dB）对应的频率
  • 相位穿越频率 ωg\omega_gωg​：φ(ωg)=−180∘\varphi(\omega_g) = -180^\circφ(ωg​)=−180∘对应的频率

判据的几何解释

在伯德图上：

  • 负实轴：对应相频特性−180∘-180^\circ−180∘线
  • 单位圆：对应幅频特性0 dB线

判断方法：

  1. 查看A=0A=0A=0 dB处频率的相位是否大于−180∘-180^\circ−180∘
  2. 如果大于，相位穿越频率为右侧首次越过−180∘-180^\circ−180∘处的频率
  3. 如果小于，相位穿越频率为左侧末次越过−180∘-180^\circ−180∘处的频率

适用条件

对数频率稳定判据仅适用于最小相位系统（开环系统无正零点）。对于非最小相位系统，不能直接采用对数稳定判据进行稳定性分析，但奈奎斯特稳定判据仍然适用。

5.3.4 频域稳定裕度

稳定裕度的概念

相对稳定性：系统距离失稳还有多少裕度，反映系统稳定性的程度。

物理意义：

  1. 冲击响应扩幅到什么程度，系统不满足渐进稳定性的条件
  2. 系统极点向右平移多少，右半平面出现极点

相角裕度

定义：开环传递函数在幅值穿越频率ωc\omega_cωc​处，相频特性距−180∘-180^\circ−180∘的相位差值，称为相角裕度γ\gammaγ。

数学表达式：

γ=180∘+φ(ωc)\gamma = 180^\circ + \varphi(\omega_c)γ=180∘+φ(ωc​)

物理意义：在ωc\omega_cωc​处，系统相位滞后γ\gammaγ，闭环系统达到临界稳定。

幅值裕度

定义：开环传递函数在相角穿越频率ωg\omega_gωg​处，幅频特性的倒数，称为幅值裕度hhh。

数学表达式：

h=1A(ωg)或hdB=−20lg⁡A(ωg)h = \frac{1}{A(\omega_g)} \quad \text{或} \quad h_{\text{dB}} = -20\lg A(\omega_g)h=A(ωg​)1​或hdB​=−20lgA(ωg​)

裕度的正负意义

  • 相角裕度：γ>0\gamma > 0γ>0表示系统稳定，γ<0\gamma < 0γ<0表示系统不稳定
  • 幅值裕度：h>1h > 1h>1（hdB>0h_{\text{dB}} > 0hdB​>0）表示系统稳定，h<1h < 1h<1（hdB<0h_{\text{dB}} < 0hdB​<0）表示系统不稳定

5.3.5 最小相位系统

最小相位系统的定义

最小相位系统：开环传递函数没有正零点的系统。

非最小相位系统：开环传递函数中有正零点的系统。

最小相位系统的特性：在给定的幅频特性情况下，其相移最小的系统。

最小相位系统的特点

  1. 频域特性：

    • 在保持幅频响应不变的情况下，相移最小
    • 系统的零点位于复平面左半平面

  2. 时域特性：

    • 非最小相位系统必然出现负超调
    • 两个系统并联，其中与变化率相关的分量具有负增益（“对着干”）

时延环节与非最小相位系统

时延环节具有类似的频率特性：幅值不变，相角滞后。具有开环正零点或者延时环节的系统为非最小相位系统。

G(s)G(s)G(s)与−G(s)-G(s)−G(s)的关系

开环传递函数G(s)G(s)G(s)与−G(s)-G(s)−G(s)之间存在以下关系：

  1. 伯德图：

    • 幅频特性一致
    • 相频特性上下移180∘180^\circ180∘

  2. 奈奎斯特图：

    • 关于原点对称

  3. 闭环稳定性：

    • 具有差异性
    • 可以视为不同的反馈结构

对数频率稳定判据的适用性

对于非最小相位系统：

  • 奈奎斯特稳定判据适用
  • 对数频率稳定判据不适用

原因：在推导对应关系时，已经暗含开环系统为0∘0^\circ0∘系统（0频对应的相位为−90∘×v-90^\circ \times v−90∘×v）。

5.3.6 映射定理

映射定理：已知F(s)F(s)F(s)为复平面上的有理映射，具有有限个零点和极点。已知原平面上不通过F(s)F(s)F(s)任何零、极点的任意封闭曲线。若该曲线包围F(s)F(s)F(s)的nzn_znz​个零点和npn_pnp​个极点，当sss以顺时针方向沿封闭曲线移动1周时，则像平面内的像轨迹以顺时针方向绕原点旋转nz−npn_z - n_pnz​−np​圈。

N=nz−npN = n_z - n_pN=nz​−np​

  1. 原平面到像平面的映射：

    • 原平面内的一条封闭曲线，在像平面内仍为封闭曲线
    • 奈奎斯特图即为传递函数映射下虚轴的像

  2. 稳定性分析：

    • 通过映射定理分析闭环稳定性

5.3.8 小结与总结

核心概念总结

频域稳定性分析方法

  1. 奈奎斯特稳定判据：基于开环奈奎斯特图包围(−1,0)(-1,0)(−1,0)点的情况判断闭环稳定性
  2. 对数频率稳定判据：基于伯德图的幅值穿越频率和相位穿越频率关系判断稳定性
  3. 频域稳定裕度：相角裕度和幅值裕度，定量描述系统稳定性程度
  4. 最小相位系统：无正零点的系统，具有最小的相位滞后
  5. 映射定理：复平面映射的基本原理，奈奎斯特判据的理论基础

关键参数定义

  1. 幅值穿越频率ωc\omega_cωc​：A(ωc)=1A(\omega_c) = 1A(ωc​)=1（0 dB）对应的频率
  2. 相位穿越频率ωg\omega_gωg​：φ(ωg)=−180∘\varphi(\omega_g) = -180^\circφ(ωg​)=−180∘对应的频率
  3. 相角裕度γ\gammaγ：γ=180∘+φ(ωc)\gamma = 180^\circ + \varphi(\omega_c)γ=180∘+φ(ωc​)
  4. 幅值裕度hhh：h=1/A(ωg)h = 1/A(\omega_g)h=1/A(ωg​)或hdB=−20lg⁡A(ωg)h_{\text{dB}} = -20\lg A(\omega_g)hdB​=−20lgA(ωg​)

重要方法总结

稳定性判断步骤

  1. 奈奎斯特判据：

    • 绘制开环奈奎斯特图
    • 计算逆时针包围(−1,0)(-1,0)(−1,0)的圈数
    • 与开环正极点个数比较

  2. 对数频率判据：

    • 绘制开环伯德图
    • 确定幅值穿越频率和相位穿越频率
    • 检查判据条件

  3. 稳定裕度计算：

    • 计算幅值穿越频率ωc\omega_cωc​
    • 计算相角裕度γ\gammaγ
    • 计算相位穿越频率ωg\omega_gωg​
    • 计算幅值裕度hhh

系统设计考虑

  1. 稳定性要求：系统必须稳定
  2. 性能要求：足够的稳定裕度保证鲁棒性
  3. 参数选择：在稳定范围内选择满足性能要求的参数

设计权衡与工程考虑

稳定性与性能的矛盾

  1. 增益选择：增益越大，响应越快，但稳定性越差
  2. 裕度要求：裕度越大，系统越稳定，但响应可能变慢
  3. 鲁棒性：足够的裕度保证系统对参数变化的鲁棒性

工程经验

  1. 相角裕度：通常要求30∘∼60∘30^\circ \sim 60^\circ30∘∼60∘
  2. 幅值裕度：通常要求h>2h > 2h>2（6 dB）
  3. 设计顺序：先保证稳定性，再优化性能

经验法则

  1. 最小相位系统：可用对数频率判据简化分析
  2. 非最小相位系统：必须用奈奎斯特判据
  3. 虚轴极点：需要特殊处理，构建”D”型围线

  3. 鲁棒性评估：评估系统对参数变化的敏感度
  4. 故障诊断：通过频率特性变化诊断系统故障
  5. 性能优化：在稳定范围内优化系统性能

常见错误与注意事项

  1. 判据适用条件：对数频率判据仅适用于最小相位系统
  2. 虚轴极点处理：系统型别大于0时需要特殊处理
