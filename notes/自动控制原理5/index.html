稳定性分析的基本概念

稳定性的定义

稳定性：系统受到扰动后其运动保持在有限边界的区域内或回复到原平衡状态的性能。

分析稳定性的两个基本条件

  1. 存在平衡状态（理论上）
  2. 存在扰动（实际情况）

稳定性的三种基本类型

  1. 稳定：系统受到扰动后能够回复到原平衡状态
  2. 临界稳定：系统受到扰动后保持有界运动但不回复
  3. 不稳定：系统受到扰动后运动无界

具有稳定性的两种形式

  1. 运动有界：系统响应保持在有限范围内
  2. 回复到原平衡状态：系统最终回到初始平衡点

线性系统与非线性系统的稳定性区别

  • 非线性系统：存在多个平衡点，稳定性是相对于特定平衡点的
  • 线性系统：平衡点只有一个，稳定性是全局的

渐进稳定性与全局渐进稳定性

  1. 渐进稳定性：当时间趋于无穷大时，受扰运动均回复到原平衡状态
  2. 全局渐进稳定性：对于任意初始扰动引起的受扰运动，系统均是渐进稳定的

重要结论：线性系统的稳定即是全局渐进稳定。

线性系统稳定性的充要条件

充要条件：系统特征方程的根全部具有负实部（传递函数的极点全部具有负实部）。

数学表达：对于特征方程

ansn+an−1sn−1+⋯+a1s+a0=0a_n s^n + a_{n-1} s^{n-1} + \cdots + a_1 s + a_0 = 0an​sn+an−1​sn−1+⋯+a1​s+a0​=0

系统稳定的充要条件是所有根sis_isi​满足：

Re(si)<0,i=1,2,…,n\text{Re}(s_i) < 0, \quad i = 1, 2, \ldots, nRe(si​)<0,i=1,2,…,n

理解：负实部保证了系统的响应随时间衰减，这是稳定性的数学本质。

劳斯判据的原理与构建

劳斯判据解决的问题

当系统的阶数大于4时，直接求解特征方程的根非常困难。劳斯判据提供了一种代数方法，无需计算根的具体值，仅通过特征方程的系数即可判断根的分布。

系统稳定的必要条件

考虑特征多项式：

ansn+an−1sn−1+⋯+a1s+a0=0a_n s^n + a_{n-1} s^{n-1} + \cdots + a_1 s + a_0 = 0an​sn+an−1​sn−1+⋯+a1​s+a0​=0

系统稳定的必要条件是：所有系数ai>0a_i > 0ai​>0（或同号）。

劳斯表的构建步骤

Step 01：确定劳斯表的行数

对于n阶系统，劳斯表有n+1行。

Step 02：填充前两行

从最高阶项系数开始，按照从上到下、从左到右的顺序填充：

  • 第一行：sn,sn−2,sn−4,…s^n, s^{n-2}, s^{n-4}, \ldotssn,sn−2,sn−4,…
  • 第二行：sn−1,sn−3,sn−5,…s^{n-1}, s^{n-3}, s^{n-5}, \ldotssn−1,sn−3,sn−5,…

Step 03：计算后续行

从第三行开始，应用规则计算：

bi=−1ai−1,1∣ai−2,1ai−2,j+1ai−1,1ai−1,j+1∣b_i = -\frac{1}{a_{i-1,1}} \begin{vmatrix} a_{i-2,1} & a_{i-2,j+1} \\ a_{i-1,1} & a_{i-1,j+1} \end{vmatrix}bi​=−ai−1,1​1​​ai−2,1​ai−1,1​​ai−2,j+1​ai−1,j+1​​​

其中ai,ja_{i,j}ai,j​表示第i行第j列的元素。

记忆口诀：固首移尾、负行列式、左下归一。

劳斯判据

劳斯判据：劳斯表首列极性变换的次数 = 特征方程根位于右半平面的数目。

  • 无极性变化：所有根位于左半平面，系统稳定
  • 有极性变化：有根位于右半平面，系统不稳定
  • 极性变化次数：右半平面根的个数

劳斯表的特殊情况和处理方法

情况一：首列出现零元素

处理方法1：用极小量ε代替

用一个小正数ε代替0，继续计算劳斯表，然后令ε→0判断符号。

处理方法2：构建对偶多项式

构建对偶多项式D(s)=snD(1/s)D(s) = s^n D(1/s)D(s)=snD(1/s)，然后对D(s)D(s)D(s)应用劳斯判据。

情况二：某一行全为零

原因分析

某一行全为零表明存在纯偶数阶多项式为原多项式的因式。

处理方法

  1. 用上一行构建辅助多项式A(s)A(s)A(s)
  2. 对A(s)A(s)A(s)求导得到A′(s)A'(s)A′(s)
  3. 用A′(s)A'(s)A′(s)的系数代替全零行
  4. 继续计算劳斯表

辅助多项式的根分布特点

纯偶数阶多项式的根必然关于原点对称且关于实轴对称：

  • 一对实根（在实轴上，互为相反数）
  • 一对纯虚根（在虚轴上）
  • 两对关于原点对称的复根

相对稳定性分析

相对稳定性的概念

相对稳定性：系统极点向右平移多少，右半平面会出现极点。它量化了系统的”稳定程度”。

分析方法

  1. 平移变换：令s=z−σs = z - σs=z−σ，将原特征方程转换为关于z的方程
  2. 应用劳斯判据：对变换后的方程应用劳斯判据
  3. 确定临界值：找到使系统变为临界稳定的σ值

相对稳定性指标

σ值可以作为稳定性的定量指标：

  • σ越大，系统相对稳定性越好
  • σ=0对应临界稳定
  • σ<0表示系统不稳定

示例：相对稳定性计算

已知闭环系统传递函数：

Φ(s)=1s2+5s+6\Phi(s) = \frac{1}{s^2 + 5s + 6}Φ(s)=s2+5s+61​

特征方程：s2+5s+6=0s^2 + 5s + 6 = 0s2+5s+6=0

令s=z−2s = z - 2s=z−2，代入得：

(z−2)2+5(z−2)+6=z2+z=0(z-2)^2 + 5(z-2) + 6 = z^2 + z = 0(z−2)2+5(z−2)+6=z2+z=0

劳斯表：

z1z^1z110
z0z^0z00

分析：系统在平移2个单位后变为临界稳定，因此相对稳定性指标σ=2。

理解：冲击响应乘以exp⁡(2t)\exp(2t)exp(2t)（扩幅）后为临界稳定，说明原系统有2个单位的稳定裕度。

结论：相对稳定性指标σ=0.59，系统有0.59个单位的稳定裕度。

小结与总结

核心概念总结

  1. 稳定性定义：系统受到扰动后其运动保持在有限边界区域内或回复到原平衡状态的性能。

  2. 稳定性类型：

    • 稳定：回复到原平衡状态
    • 临界稳定：保持有界运动但不回复
    • 不稳定：运动无界

  3. 线性系统稳定性充要条件：特征方程的所有根具有负实部（传递函数的所有极点位于左半平面）。

  4. 劳斯判据：基于特征方程系数的代数稳定性判据，无需计算根的具体值。

重要方法总结

劳斯表构建方法

  1. 确定行数：n阶系统→n+1行
  2. 填充前两行：按幂次交错填充系数
  3. 计算后续行：应用”固首移尾、负行列式、左下归一”规则

特殊情况处理

  1. 首列出现零：
    • 方法1：用极小量ε代替，令ε→0判断
    • 方法2：构建对偶多项式
  2. 某行全为零：
    • 构建辅助多项式A(s)A(s)A(s)
    • 对A(s)A(s)A(s)求导得A′(s)A'(s)A′(s)
    • 用A′(s)A'(s)A′(s)系数代替全零行

参数稳定性分析

  1. 建立含参数的特征方程
  2. 构建参数化劳斯表
  3. 根据首列符号确定参数稳定范围

相对稳定性分析

  1. 令s=z−σs = z - σs=z−σ进行平移变换
  2. 对变换后的方程应用劳斯判据
  3. 确定使系统临界稳定的σ值

学习要点

  1. 理解稳定性物理意义：不仅掌握数学判据，更要理解稳定性的物理本质
  2. 熟练构建劳斯表：通过大量练习掌握劳斯表的构建技巧
  3. 掌握特殊情况处理：能够正确处理首列为零和全零行的情况
  4. 应用参数分析：能够应用劳斯判据进行系统参数设计
  5. 理解相对稳定性：掌握稳定性程度的定量分析方法

工程应用价值

  1. 控制系统设计：确保设计的控制系统稳定
  2. 参数整定：确定控制器参数的稳定范围
  3. 稳定性评估：评估现有系统的稳定裕度
  4. 故障诊断：通过稳定性分析诊断系统问题
  5. 鲁棒性设计：考虑参数变化时的系统稳定性

常见错误与注意事项

  1. 系数符号错误：确保特征方程系数正确
  2. 劳斯表计算错误：仔细检查行列式计算
  3. 特殊情况处理不当：正确识别和处理特殊情况
  4. 参数范围遗漏：检查所有不等式条件
  5. 物理意义忽视：不要只做数学计算，要理解物理意义

稳定性分析是控制系统设计的基石，劳斯判据作为经典的代数稳定性判据，在工程实践中具有重要应用价值。通过本章学习，应能熟练应用劳斯判据进行系统稳定性分析和参数设计，为后续的控制器设计奠定基础。
