稳态误差的基本概念

误差的定义

误差：输出信号相对于输入信号的偏差，记作e(t)e(t)e(t)。

对于反馈控制系统，误差通常定义为：

e(t)=r(t)−y(t)e(t) = r(t) - y(t)e(t)=r(t)−y(t)

其中：

  • r(t)r(t)r(t)：参考输入信号
  • y(t)y(t)y(t)：系统输出信号

稳态误差的定义

稳态误差：当时间趋于正无穷时，输出信号相对于输入信号的偏差，记作esse_{ss}ess​。

数学表达：

ess=lim⁡t→∞e(t)=lim⁡t→∞[r(t)−y(t)]e_{ss} = \lim_{t \to \infty} e(t) = \lim_{t \to \infty} [r(t) - y(t)]ess​=t→∞lim​e(t)=t→∞lim​[r(t)−y(t)]

误差的两种表示形式

  1. 误差反馈形式：

    R(s) → ⊕ → E(s) → [T(s)] → Y(s)
       ↑ (-)
       └───────┘

  2. 偏差形式：

    R(s) → ⊕ → E(s) → [G(s)] → Y(s)
       ↑ (-)
       └───────┘

终值定理的应用

对于稳定的系统，可以使用终值定理计算稳态误差：

ess=lim⁡s→0sE(s)=lim⁡s→0s[R(s)−Y(s)]e_{ss} = \lim_{s \to 0} sE(s) = \lim_{s \to 0} s[R(s) - Y(s)]ess​=s→0lim​sE(s)=s→0lim​s[R(s)−Y(s)]

其中E(s)E(s)E(s)是误差e(t)e(t)e(t)的拉普拉斯变换。

典型激励信号

控制系统分析中常用的三种典型激励信号：

1. 阶跃信号（Step Signal）

物理意义：位置恒定
时间函数：

像函数：

应用示例：位置跟踪控制，如卫星的轨道平面控制、天线的指向控制。

2. 斜坡信号（Ramp Signal）

物理意义：速度恒定
时间函数：

r(t)={0,t<0At,t≥0r(t) = \begin{cases} 0, & t < 0 \\ At, & t \geq 0 \end{cases}r(t)={0,At,​t<0t≥0​

像函数：

R(s)=As2R(s) = \frac{A}{s^2}R(s)=s2A​

应用示例：速度跟踪控制，如卫星的对地观测、移动目标的跟踪。

3. 抛物信号（Parabola Signal）

物理意义：加速度恒定
时间函数：

r(t)={0,t<0A2t2,t≥0r(t) = \begin{cases} 0, & t < 0 \\ \frac{A}{2}t^2, & t \geq 0 \end{cases}r(t)={0,2A​t2,​t<0t≥0​

像函数：

R(s)=As3R(s) = \frac{A}{s^3}R(s)=s3A​

应用示例：加速度跟踪控制，如导弹等加速移动目标的跟踪。

重要结论

输入信号类型的不同会导致系统误差规律不同。系统对不同类型信号的跟踪能力不同，这反映了系统的”型别”特性。

重要结论：

  1. 系统型别决定了系统能够无误差跟踪的信号类型
  2. 0型系统只能跟踪阶跃信号（有静差）
  3. I型系统可以无误差跟踪阶跃信号，有差跟踪斜坡信号
  4. II型系统可以无误差跟踪阶跃和斜坡信号，有差跟踪抛物信号

减小稳态误差的措施

1. 提高系统型别

在前向通路中增加积分环节，可以提高系统型别：

  • 增加一个积分环节：0型→I型
  • 增加两个积分环节：0型→II型

优点：可以消除对某些类型信号的稳态误差
缺点：可能降低系统稳定性，需要谨慎设计

2. 增大开环增益

增大开环增益KKK可以减小稳态误差：

  • 对于0型系统：ess=A1+K≈AKe_{ss} = \frac{A}{1+K} ≈ \frac{A}{K}ess​=1+KA​≈KA​（当KKK很大时）
  • 对于I型系统：ess=AKe_{ss} = \frac{A}{K}ess​=KA​

优点：简单有效
缺点：可能引起系统不稳定，放大测量噪声

  • ωd=ωn1−ζ2\omega_d = \omega_n \sqrt{1-\zeta^2}ωd​=ωn​1−ζ2​

2. 峰值时间 tpt_ptp​

定义：响应曲线超过稳态值达到第一个峰值所需的时间。

物理意义：反映系统达到最大超调的时间。

计算方法：
对于二阶系统：

tp=πωdt_p = \frac{\pi}{\omega_d}tp​=ωd​π​

3. 超调量 σ%\sigma\%σ%

定义：输出量的最大值与稳态值之差与稳态值的百分比。

数学表达：

σ%=y(tp)−y(∞)y(∞)×100%\sigma\% = \frac{y(t_p) - y(\infty)}{y(\infty)} \times 100\%σ%=y(∞)y(tp​)−y(∞)​×100%

物理意义：反映系统响应的平稳性。σ%\sigma\%σ%越小，系统响应越平稳。

计算方法：

4. 调节时间 tst_sts​

定义：响应曲线达到并保持在容许误差范围（通常为±5%或±2%）所需的最短时间。

物理意义：反映系统过渡过程的持续时间。tst_sts​越小，系统快速性越好。

计算方法：
对于二阶系统：

  • ±5%误差带：ts≈3ζωnt_s ≈ \frac{3}{\zeta\omega_n}ts​≈ζωn​3​
  • ±2%误差带：ts≈4ζωnt_s ≈ \frac{4}{\zeta\omega_n}ts​≈ζωn​4​

性能指标之间的关系

  1. 快速性与平稳性的矛盾：

    • 减小trt_rtr​和tst_sts​（提高快速性）通常需要增大ωn\omega_nωn​
    • 减小σ%\sigma\%σ%（提高平稳性）需要增大ζ\zetaζ
    • 但ζ\zetaζ过大会降低快速性

  2. 设计权衡：

    • 工程上通常取ζ=0.707\zeta = 0.707ζ=0.707作为最佳阻尼比
    • 此时σ%≈4.3%\sigma\% ≈ 4.3\%σ%≈4.3%，兼顾快速性和平稳性

无振荡响应

对于过阻尼系统（ζ>1\zeta > 1ζ>1）和临界阻尼系统（ζ=1\zeta = 1ζ=1）：

  • 没有峰值时间tpt_ptp​和超调量σ%\sigma\%σ%的指标
  • 性能主要由上升时间trt_rtr​和调节时间tst_sts​描述

3.3.4 小结与总结

核心概念总结

稳态误差部分

  1. 误差定义：输出相对于输入的偏差e(t)=r(t)−y(t)e(t) = r(t) - y(t)e(t)=r(t)−y(t)
  2. 稳态误差：ess=lim⁡t→∞e(t)e_{ss} = \lim_{t \to \infty} e(t)ess​=limt→∞​e(t)
  3. 误差常数：
    • 位置误差常数Kp=lim⁡s→0G(s)K_p = \lim_{s \to 0} G(s)Kp​=lims→0​G(s)
    • 速度误差常数Kv=lim⁡s→0sG(s)K_v = \lim_{s \to 0} sG(s)Kv​=lims→0​sG(s)
    • 加速度误差常数Ka=lim⁡s→0s2G(s)K_a = \lim_{s \to 0} s^2G(s)Ka​=lims→0​s2G(s)
  4. 系统型别：开环传递函数中积分环节的个数NNN
  5. 型别与误差关系：
    • 0型系统：有差跟踪阶跃信号
    • I型系统：无差跟踪阶跃，有差跟踪斜坡
    • II型系统：无差跟踪阶跃和斜坡，有差跟踪抛物

时域性能指标部分

  1. 上升时间trt_rtr​：10%~90%稳态值的时间，反映快速性
  2. 峰值时间tpt_ptp​：达到第一个峰值的时间
  3. 超调量σ%\sigma\%σ%：最大超调百分比，反映平稳性
  4. 调节时间tst_sts​：进入误差带的时间，反映过渡过程持续时间

重要方法总结

稳态误差分析方法

  1. 判断系统是否为单位负反馈结构
  2. 计算开环传递函数G(s)G(s)G(s)
  3. 确定系统型别NNN
  4. 计算相应的误差常数
  5. 根据输入类型计算稳态误差

性能指标计算方法（二阶系统）

  1. 自然频率ωn\omega_nωn​和阻尼比ζ\zetaζ
  2. 阻尼振荡频率ωd=ωn1−ζ2\omega_d = \omega_n \sqrt{1-\zeta^2}ωd​=ωn​1−ζ2​
  3. 角度β=arctan⁡(1−ζ2ζ)\beta = \arctan\left(\frac{\sqrt{1-\zeta^2}}{\zeta}\right)β=arctan(ζ1−ζ2​​)
  4. 应用公式计算各性能指标

减小稳态误差的措施

  1. 提高系统型别（增加积分环节）
  2. 增大开环增益
  3. 采用复合控制（前馈补偿）
  4. 扰动补偿
  5. 鲁棒设计降低灵敏度

设计权衡与工程考虑

  1. 稳定性与精度的矛盾：

    • 提高型别和增益可减小误差，但可能降低稳定性
    • 需要平衡稳定性和精度要求

  2. 快速性与平稳性的矛盾：

    • 减小trt_rtr​和tst_sts​需要增大ωn\omega_nωn​
    • 减小σ%\sigma\%σ%需要增大ζ\zetaζ
    • 最佳折衷：ζ=0.707\zeta = 0.707ζ=0.707

  3. 噪声与精度的矛盾：

    • 增大增益减小误差，但放大测量噪声
    • 需要”精准”的测量实现”精准”的控制

  4. 鲁棒性与性能的矛盾：

    • 高增益系统对参数变化敏感
    • 需要鲁棒设计保证性能一致性

关键公式回顾

  1. 稳态误差公式：

    • 阶跃输入：ess=A1+Kpe_{ss} = \frac{A}{1+K_p}ess​=1+Kp​A​
    • 斜坡输入：ess=AKve_{ss} = \frac{A}{K_v}ess​=Kv​A​
    • 抛物输入：ess=AKae_{ss} = \frac{A}{K_a}ess​=Ka​A​

  2. 二阶系统性能指标：

    • tr=π−βωdt_r = \frac{\pi - \beta}{\omega_d}tr​=ωd​π−β​
    • tp=πωdt_p = \frac{\pi}{\omega_d}tp​=ωd​π​
    • σ%=e−ζπ1−ζ2×100%\sigma\% = e^{-\frac{\zeta\pi}{\sqrt{1-\zeta^2}}} \times 100\%σ%=e−1−ζ2​ζπ​×100%
    • ts≈3ζωnt_s ≈ \frac{3}{\zeta\omega_n}ts​≈ζωn​3​（±5%）或 4ζωn\frac{4}{\zeta\omega_n}ζωn​4​（±2%）

  3. 阻尼振荡频率：

    • ωd=ωn1−ζ2\omega_d = \omega_n \sqrt{1-\zeta^2}ωd​=ωn​1−ζ2​
    • β=arctan⁡(1−ζ2ζ)\beta = \arctan\left(\frac{\sqrt{1-\zeta^2}}{\zeta}\right)β=arctan(ζ1−ζ2​​)

工程应用价值

  1. 控制系统设计：根据性能要求确定系统结构和参数
  2. 性能评估：评估现有系统的稳态和动态性能
  3. 控制器整定：调整控制器参数满足性能指标
  4. 系统改进：识别性能瓶颈并采取改进措施
  5. 鲁棒性分析：分析参数变化对性能的影响

常见错误与注意事项

  1. 单位负反馈假设：误差常数定义基于单位负反馈系统
  2. 稳定性前提：终值定理和性能指标计算要求系统稳定
  3. 型别判断错误：正确识别积分环节个数
  4. 公式适用条件：性能指标公式仅适用于二阶系统
  5. 设计矛盾忽视：注意稳定性、精度、快速性、平稳性之间的矛盾

稳态误差和时域性能指标是控制系统设计的核心内容。通过本章学习，应能熟练分析系统的稳态和动态性能，根据性能要求设计合适的控制系统结构，并在各种矛盾要求之间找到最佳平衡点。
