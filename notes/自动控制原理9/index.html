5.1.1 频域分析与时域分析的比较

时域分析

  • 输入信号：阶跃输入
  • 分析对象：二阶系统在时间域的瞬态响应
  • 评价指标：时域性能指标（上升时间、调节时间、超调量等）
  • 特点：直接反映系统的时间响应特性

频域分析

  • 输入信号：谐波（正弦）输入
  • 分析对象：二阶或高阶系统在时间域的稳态响应
  • 表示方法：使用曲线、图形更直观反映系统结构参数与响应的关系
  • 优势：能够指出改善系统性能的途径
  • 特点：通过频率特性分析系统的动态性能

比较总结

分析类型输入信号分析重点表示方法应用特点
时域分析阶跃信号瞬态响应时间函数直接、直观
频域分析正弦信号稳态响应频率曲线揭示系统结构特性

5.1.4 频率响应的基本概念

频率响应的定义

对于一个稳定的线性系统，当输入为正弦信号时：

xi(t)=Xisin⁡(ωt)x_i(t) = X_i \sin(\omega t)xi​(t)=Xi​sin(ωt)

系统的稳态输出为同频率的正弦信号：

xo(t)=Xo(ω)sin⁡[ωt+φ(ω)]x_o(t) = X_o(\omega) \sin[\omega t + \varphi(\omega)]xo​(t)=Xo​(ω)sin[ωt+φ(ω)]

其中：

  • Xo(ω)X_o(\omega)Xo​(ω)：输出幅值，是频率 ω\omegaω 的函数
  • φ(ω)\varphi(\omega)φ(ω)：输出相位，是频率 ω\omegaω 的函数

频率响应的物理意义

  1. 稳态频率一致性：输出与输入同频率
  2. 幅值变化：输出幅值随频率变化
  3. 相位偏移：输出相位相对输入有偏移

频率响应的数学描述

根据微分方程解的理论，若对系统输入谐波信号 xi(t)=Xisin⁡(ωt)x_i(t) = X_i \sin(\omega t)xi​(t)=Xi​sin(ωt)，系统的稳态输出响应也为同一频率的谐波信号，但幅值和相位发生了变化。

5.1.5 频率特性的定义与性质

频率特性的定义

频率特性是对系统频率响应特性的完整描述，包括：

  1. 幅频特性：稳态输出与输入谐波的幅值比

    A(ω)=Xo(ω)XiA(\omega) = \frac{X_o(\omega)}{X_i}A(ω)=Xi​Xo​(ω)​

  2. 相频特性：稳态输出与输入谐波的相位差

    φ(ω)=∠Xo(ω)−∠Xi\varphi(\omega) = \angle X_o(\omega) - \angle X_iφ(ω)=∠Xo​(ω)−∠Xi​

  3. 频率特性函数：关于谐波频率的复变函数

    G(jω)=A(ω)ejφ(ω)G(j\omega) = A(\omega)e^{j\varphi(\omega)}G(jω)=A(ω)ejφ(ω)

频率特性的性质

  1. 复变函数：G(jω)G(j\omega)G(jω) 是 ω\omegaω 的复变函数
  2. 量纲一致性：频率特性的量纲就是传递函数的量纲，也是输出信号与输入信号的量纲之比
  3. 与传递函数的关系：G(jω)G(j\omega)G(jω) 就是 G(s)G(s)G(s) 中的 s=jωs = j\omegas=jω 时的结果

频率特性的表示形式

  1. 代数形式：G(jω)=Re[G(jω)]+jIm[G(jω)]G(j\omega) = \text{Re}[G(j\omega)] + j\text{Im}[G(j\omega)]G(jω)=Re[G(jω)]+jIm[G(jω)]
  2. 指数形式：G(jω)=A(ω)ejφ(ω)G(j\omega) = A(\omega)e^{j\varphi(\omega)}G(jω)=A(ω)ejφ(ω)
  3. 极坐标形式：G(jω)=A(ω)∠φ(ω)G(j\omega) = A(\omega)\angle\varphi(\omega)G(jω)=A(ω)∠φ(ω)

5.1.6 频率特性与传递函数的关系

基本关系

对于线性定常系统，频率特性 G(jω)G(j\omega)G(jω) 与传递函数 G(s)G(s)G(s) 之间存在直接关系：

G(jω)=G(s)∣s=jωG(j\omega) = G(s)\big|_{s=j\omega}G(jω)=G(s)​s=jω​

物理意义

  1. s域到频域的映射：将拉普拉斯变量 sss 替换为 jωj\omegajω，即从复频域映射到频域
  2. 系统特性的不同视角：
    • 传递函数 G(s)G(s)G(s)：描述系统在复频域的特性
    • 频率特性 G(jω)G(j\omega)G(jω)：描述系统在频域的特性

重要结论

将 G(jω)G(j\omega)G(jω) 与 G(s)G(s)G(s) 比较不难看出，G(jω)G(j\omega)G(jω) 就是 G(s)G(s)G(s) 中的 s=jωs = j\omegas=jω 时的结果，是 ω\omegaω 的复变函数。显然，频率特性的量纲就是传递函数的量纲，也是输出信号与输入信号的量纲之比。

      A(0.1)=100.12+1=101.01≈9.95A(0.1) = \frac{10}{\sqrt{0.1^2 + 1}} = \frac{10}{\sqrt{1.01}} \approx 9.95A(0.1)=0.12+1​10​=1.01​10​≈9.95

      稳态响应幅值：2×9.95=19.902 \times 9.95 = 19.902×9.95=19.90

      稳态响应幅值：2×0.995=1.992 \times 0.995 = 1.992×0.995=1.99

  3. 结果分析：

    • 低频 (ω=0.1\omega = 0.1ω=0.1) 时，系统增益接近10，幅值较大
    • 中频 (ω=1\omega = 1ω=1) 时，系统增益约为7.07
    • 高频 (ω=10\omega = 10ω=10) 时，系统增益接近1，幅值较小

    结论：该系统具有低通特性，对低频信号增益大，对高频信号增益小。

5.1.8 小结与总结

核心概念总结

频域分析的基本思想

  1. 分析对象：系统在正弦输入下的稳态响应
  2. 表示方法：频率特性曲线
  3. 优势：直观反映系统结构参数与响应的关系

频率特性

  1. 定义：系统对正弦输入的稳态响应特性
  2. 组成：
    • 幅频特性：输出与输入的幅值比
    • 相频特性：输出与输入的相位差
  3. 表示形式：G(jω)=A(ω)ejφ(ω)G(j\omega) = A(\omega)e^{j\varphi(\omega)}G(jω)=A(ω)ejφ(ω)

  2. 物理意义：从复频域到频域的映射
  3. 量纲一致性：频率特性的量纲与传递函数相同

欧拉定理

  2. 应用：简化复数运算，表示正弦信号

  1. 实验测量：测量系统在不同频率下的幅值和相位
  2. 参数拟合：根据测量数据拟合系统参数
  3. 模型验证：验证辨识模型的准确性
