5.4.1 控制系统校正概述

控制系统校正的目的

控制系统校正的目的是通过引入适当的校正装置，改善系统的性能指标，使其满足设计要求。主要改善的方面包括：

  1. 稳定性：提高系统的稳定裕度
  2. 快速性：改善系统的响应速度
  3. 准确性：减小稳态误差
  4. 鲁棒性：增强系统对参数变化的适应性

校正的基本思想

通过改变系统的频率特性（幅频特性和相频特性），使系统满足性能指标要求。校正装置可以改变系统的零极点分布，从而改变系统的动态性能。

5.4.2 频域指标与时域指标的关系

二阶系统的性能指标

对于典型的二阶系统，时域性能指标与频域性能指标之间存在确定的对应关系。

时域性能指标

  • 调节时间 ts​：系统响应达到并保持在稳态值允许误差范围内所需的时间
  • 上升时间 tr​：响应从稳态值的10%上升到90%所需的时间
  • 超调量 σ%：响应最大峰值与稳态值的相对误差
  • 峰值时间 tp​：响应达到第一个峰值所需的时间

二阶系统的物理特性

  • 自然频率 ωn​：无阻尼振荡频率
  • 阻尼比 ζ：衰减与振荡的比值
  • 阻尼频率 ωd​：阻尼振荡频率，ωd​=ωn​1−ζ2​
  • 衰减系数 σ：特征根实部绝对值，σ=ζωn​

频域性能指标

闭环系统频域指标

  • 带宽 ωb​：闭环系统幅频特性下降3 dB时所对应的频率
  • 谐振频率 ωr​：闭环幅频特性出现峰值时的频率
  • 谐振峰值 Mr​：闭环幅频特性的最大值

开环系统频域指标

  • 截止频率 ωc​：开环幅频特性为1（0 dB）时的频率
  • 相角裕度 γ：γ=180∘+φ(ωc​)
  • 幅值裕度 h：h=1/A(ωg​)，其中φ(ωg​)=−180∘
  • 误差常数 C：位置、速度、加速度误差常数

指标对应关系

二阶系统的近似关系

对于单位负反馈的典型二阶系统：

  1. 相角裕度与阻尼比：

    γ≈100ζ(0≤ζ≤0.7)

    或更精确地：

    γ=arctan​1+4ζ4​−2ζ2​2ζ​​

  2. 截止频率与自然频率：

    ωc​≈ωn​(当ζ≈0.7)

  3. 带宽与自然频率：

    ωb​=ωn​1−2ζ2+2−4ζ2+4ζ4​​

  • 开环系统相角裕度：对应γ=30∘∼60∘
  • 带宽：反映了系统的快速性，与调节时间对应

5.4.3 校正环节的分类

按连接方式分类

根据校正装置在系统中的连接方式，可以分为：

1. 串联校正

校正装置串联在前向通道中，结构简单，应用广泛。

2. 反馈校正

校正装置构成局部节的特性。

3. 前馈校正
  • 前置滤波校正：在参考输入前加入校正装置
  • 扰动补偿前置校正：对扰动进行测量和补偿

4. 复合校正

结合多种校正方式，综合改善系统性能。

按校正装置特性分类

1. 超前校正环节

传递函数形式：

Gc​(s)=1+Ts1+aTs​,a>1

或

Gc​(s)=Kc​s+pc​s+zc​​,∣zc​∣<∣pc​∣

特点：

  • 极点在零点右边
  • 提供相位超前
  • 最大超前角仅与a有关： ϕm​=arcsin(a+1a−1​)
  • 最大超前角频率： ωm​=Ta​1​
2. 滞后校正环节

传递函数形式：

Gc​(s)=1+Ts1+bTs​,b<1

或

Gc​(s)=Kc​s+pc​s+zc​​,∣zc​∣>∣pc​∣

特点：

  • 零点在极点右边
  • 提供幅值衰减
  • 最大滞后角仅与b有关： ϕm​=arcsin(1+b1−b​)
  • 最大滞后角频率： ωm​=Tb​1​
3. 超前-滞后校正环节

结合超前和滞后校正的优点，传递函数形式：

Gc​(s)=(1+T1​s)(1+T2​s)(1+aT1​s)(1+bT2​s)​,a>1,b<1
4. PID校正环节
  • 比例（P）：改善响应速度，减小稳态误差
  • 积分（I）：消除稳态误差，提高系统型别
  • 微分（D）：提高稳定性，减小超调

5.4.4 串联超前校正

超前校正的作用

串联超前校正主要利用其高频相角超前特性：

  1. 提高相角裕度：增加系统的稳定性
  2. 提高截止频率：改善系统的快速性
  3. 对稳态性能影响小：不改变系统的型别和误差常数

超前校正的设计步骤

Step 1：根据稳态误差要求设计开环增益K

根据稳态误差要求确定系统的型别和误差常数，计算所需的开环增益。

Step 2：检验当前系统的相角裕度

绘制未校正系统的伯德图，计算当前的相角裕度γ0​和截止频率ωc0​。

Step 3：根据截止频率要求设计超前环节参数

  1. 确定需要的相位超前量：

    ϕm​=γdesired​−γ0​+Δ

    其中Δ=5∘∼15∘为安全裕量。

  2. 计算参数a：

    a=1−sinϕm​1+sinϕm​​

  3. 确定最大超前角频率：
    选择ωm​=ωc,desired​（期望的截止频率）

  4. 计算时间常数T：

    T=ωm​a​1​

  5. 确定校正装置：

    Gc​(s)=1+Ts1+aTs​

Step 4：验证校正后系统的性能

绘制校正后系统的伯德图，验证相角裕度、截止频率和幅值裕度是否满足要求。

设计实例

问题：已知单位负反馈系统的开环传递函数为：

G(s)=s(s+1)K​

要求：

  1. 速度跟踪误差小于10%
  2. 开环截止频率大于4.4 rad/s
  3. 相角裕度大于45°
  4. 幅值裕度大于10 dB

试设计串联超前校正装置。

解答：

  1. Step 1：设计开环增益

    • 速度误差常数：Kv​=lims→0​sG(s)=K
    • 速度跟踪误差：ess​=1/Kv​=1/K<0.1
    • 解得：K>10，取K=10

  2. Step 2：检验当前系统性能

    • 未校正系统：G0​(s)=s(s+1)10​
    • 截止频率：ωc0​≈3.16 rad/s
    • 相角裕度：γ0​≈18∘
    • 均低于指标要求，需要超前校正

  3. Step 3：设计超前环节

    • 需要相位超前量：ϕm​=45∘−18∘+10∘=37∘
    • 计算a：a=1−sin37∘1+sin37∘​≈4.0
    • 选择ωm​=ωc,desired​=4.4 rad/s
    • 计算T：T=4.44.0​1​≈0.114 s
    • 超前校正装置：Gc​(s)=1+0.114s1+4.0×0.114s​=1+0.114s1+0.456s​

  4. Step 4：验证校正后性能

    • 校正后系统：Gc​(s)G0​(s)=s(s+1)(1+0.114s)10(1+0.456s)​
    • 验证满足所有性能要求

5.4.5 串联滞后校正

滞后校正的作用

串联滞后校正主要利用其高频幅值衰减特性：

  1. 提高相角裕度：通过降低截止频率，使系统在较低频率处穿越0 dB线
  2. 改善稳态性能：可以通过提高增益来改善稳态误差，而不影响稳定性
  3. 对高频噪声有抑制作用

滞后校正的设计步骤

Step 1：根据稳态误差要求设计开差要求确定所需的开环增益，通常需要比未校正系统更高的增益。

Step 2：检验当前系统的性能指标

绘制未校正系统（带有所需增益）的伯德图，计算当前的相角裕度、截止频率和幅值裕度。

Step 3：根据相角裕度要求设计滞后环节参数

  1. 确定新的截止频率ωc′​：
    在未校正系统的相频特性上，找到相位等于−180∘+γdesired​+Δ的频率，其中Δ=5∘∼15∘为补偿滞后环节引入的相位滞后。

  2. 确定需要的幅值衰减量：
    在频率ωc′​处，未校正系统的幅值为L0​(ωc′​)，需要衰减到0 dB，即：

    20lg∣Gc​(jωc′​)∣=−L0​(ωc′​)

  3. 计算参数b：

    b=10−L0​(ωc′​)/20

  4. 选择零点频率：
    选择零点频率ωz​=1/(bT)远低于新的截止频率，通常：

    ωz​=(0.1∼0.2)ωc′​

  5. 计算时间常数T：

    T=bωz​1​

  6. 确定校正装置：

    Gc​(s)=1+Ts1+bTs​

Step 4：验证校正后系统的性能

绘制校正后系统的伯德图，验证相角裕度、截止频率和幅值裕度是否满足要求。

设计实例

问题：已知单位负反馈系统的开环传递函数为：

G(s)=s(s+1)(s+2)K​

要求：

  1. 静态速度误差常数Kv​=30 s⁻¹
  2. 相角裕度不低于40°
  3. 幅值裕度不小于10 dB
  4. 截止频率不小于2.3 rad/s

试设计串联滞后校正装置。

解答：

  1. Step 1：设计开环增益

    • 速度误差常数：Kv​=lims→0​sG(s)=K/2=30

    • 解得：K=60

    • 相角裕度：γ0​≈−20∘（系统不稳定）

    • 幅值裕度：h0​<1（负值）

    • 系统不稳定，需要滞后校正

  2. Step 3：设计滞后环节

    • 期望相角裕度：γdesired​=40∘
    • 考虑滞后环节引入的相位滞后：取Δ=12∘
    • 需要未校正系统在ωc′​处的相位：φ(ωc′​)=−180∘+40∘+12∘=−128∘
    • 在未校正系统相频特性上找到φ=−128∘对应的频率：ωc′​≈2.5 rad/s
    • 在ωc′​=2.5 rad/s处，未校正系统的幅值：L0​(2.5)≈8 dB
    • 需要衰减量：8 dB
    • 计算b：b=10−8/20≈0.4
    • 选择零点频率：ωz​=0.2ωc′​=0.5 rad/s
    • 计算T：T=bωz​1​=0.4×0.51​=5 s
    • 滞后校正装置：Gc​(s)=1+5s1+0.4×5s​=1+5s1+2s​

  3. Step 4：验证校正后性能

    • 校正后系统：Gc​(s)G0​(s)=s(s+1)(s+2)(1+5s)60(1+2s)​
    • 截止频率：ωc​≈2.5 rad/s > 2.3 rad/s，满足要求
    • 相角裕度：γ≈42∘>40∘，满足要求
    • 幅值裕度：h≈12 dB > 10 dB，满足要求
    • 速度误差常数：Kv​=30 s⁻¹，满足要求

5.4.7 小结与总结

核心概念总结

控制系统校正的目的

  1. 改善稳定性：提高相角裕度和幅值裕度
  2. 改善快速性：调整截止频率和带宽
  3. 改善准确性：减小稳态误差
  4. 增强鲁棒性：提高系统对参数变化的适应性

频域指标与时域指标的关系

  1. 相角裕度与阻尼比：γ≈100ζ（近似关系）
  2. 截止频率与自然频率：ωc​≈ωn​（当ζ≈0.7）
  3. 带宽与调节时间：带宽越大，调节时间越短
  4. 谐振峰值与超调量：Mr​越大，σ%越大

校正环节分类

  1. 按连接方式：串联校正、反馈校正、前馈校正、复合校正
  2. 按特性：超前校正、滞后校正、超前-滞后校正、PID校正

重要方法总结

串联超前校正设计步骤

  1. 根据稳态误差要求设计开环增益
  2. 检验当前系统性能
  3. 根据截止频率要求设计超前环节参数
  4. 验证校正后系统性能

串联滞后校正设计步骤

  1. 根据稳态误差要求设计开环增益
  2. 检验当前系统性能
  3. 根据相角裕度要求设计滞后环节参数
  4. 验证校正后系统性能

设计权衡与工程考虑

校正方式的选择

  1. 超前校正：适用于相角裕度不足，需要提高快速性的情况
  2. 滞后校正：适用于相角裕度不足，需要改善稳态性能的情况
  3. 超前-滞后校正：适用于需要同时改善多个性能指标的情况
  4. PID校正：适用于需要综合改善性能的情况

工程经验

  1. 相角裕度：通常要求30∘∼60∘
  2. 幅值裕度：通常要求h>2（6 dB）
  3. 截止频率：根据快速性要求确定
  4. 安全裕量：设计时考虑5∘∼15∘的安全裕量

经验法则

  1. 超前校正：最大超前角不宜超过60∘
  2. 滞后校正：零点频率应远低于新的截止频率（0.1∼0.2倍）
  3. 参数选择：在满足性能要求的前提下，尽量选择简单的校正装置

工程应用价值

  1. 系统设计：根据性能要求设计合适的校正装置
  2. 性能优化：在矛盾性能指标之间找到最佳平衡点
  3. 故障诊断：通过校正装置调整诊断系统问题
  4. 鲁棒性设计：设计对参数变化不敏感的系统
  5. 实际应用：在工业控制、航空航天、机器人等领域广泛应用

常见错误与注意事项

  1. 校正方式选择错误：根据系统问题选择正确的校正方式
  2. 参数设计不合理：参数选择不当可能导致系统性能恶化
  3. 忽略安全裕量：设计时未考虑安全裕量可能导致实际性能不达标
  4. 验证不充分：设计后未充分验证系统性能
  5. 忽略实际约束：未考虑实际系统的物理约束和实现难度

  3. 理解物理意义：不仅记住设计步骤，更要理解物理意义
  4. 系统思维：从整体角度理解校正对系统性能的影响
  5. 工程思维：培养在实际工程中应用校正方法的能力
