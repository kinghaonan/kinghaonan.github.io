3.4.1 一阶系统的性能分析

一阶系统传递函数的一般表达式

一阶系统的标准传递函数形式为：

G(s)=Ts+1K​

其中：

  • K：系统增益
  • T：时间常数

阶跃响应的时域表达式

对于单位阶跃输入r(t)=1(t)，系统的输出响应为：

y(t)=K(1−e−t/T),t≥0

时间常数的物理意义

时间常数T：反映系统的响应速度，具有以下物理意义：

  1. 表示t=0+时刻，输出信号的斜率为1/T
  2. 当t=T时，输出达到稳态值的63.2%
  3. 当t=3T时，输出达到稳态值的95%
  4. 当t=4T时，输出达到稳态值的98.2%

一阶系统的性能指标

1. 调节时间 ts​
  • ±5%误差带：ts​=3T
  • ±2%误差带：ts​=4T
2. 上升时间 tr​
  • 从10%到90%稳态值：tr​=2.2T
3. 时间常数与响应速度的关系

时间常数T越小，系统响应速度越快。任意一阶响应可以通过尺度变换获得。

重要结论

  1. 一阶系统的动态性能完全由时间常数T决定
  2. T越小，系统响应越快
  3. 所有一阶系统具有相似的响应形状，仅时间尺度不同

3.4.2 二阶系统的类型与标准形式

二阶系统的一般表示

二阶系统的标准传递函数形式为：

G(s)=s2+2ζωn​s+ωn2​ωn2​​

其中：

  • ωn​：自然频率（无阻尼自然频率）
  • ζ：阻尼比

传递函数的三种表示形式

  1. 首一标准型：

    G(s)=s2+2ζωn​s+ωn2​ωn2​​

  2. 零极点形式（zpk）：

    G(s)=(s−p1​)(s−p2​)ωn2​​

    其中p1,2​=−ζωn​±ωn​ζ2−1​

  3. 尾一标准型：

    G(s)=ωn2​1​s2+ωn​2ζ​s+11​

二阶系统的特征方程

特征方程：

s2+2ζωn​s+ωn2​=0

特征根：

s1,2​=−ζωn​±ωn​ζ2−1​

二阶系统的四种类型

根据阻尼比ζ的取值，二阶系统可分为四种类型：

阻尼比ζ特征根系统类型响应特点
ζ=0s1,2​=±jωn​无阻尼系统纯振荡，无衰减
0<ζ<1一对共轭复根欠阻尼系统衰减振荡
ζ=1重实根 s1,2​=−ωn​临界阻尼系统最快无超调响应
ζ>1两个相异实根过阻尼系统缓慢无超调响应

阻尼比的物理意义

阻尼比ζ：指数衰减率与周期振荡的比值，反映了系统的阻尼程度。

  • ζ=0：无阻尼，纯振荡
  • 0<ζ<1：欠阻尼，衰减弱于振荡
  • ζ=1：临界阻尼，衰减率与振荡频率一致
  • ζ>1：过阻尼，衰减强于振荡

注意：阻尼比小于0表示系统不稳定（正反馈）。

3.4.3 二阶系统的性能分析

关键物理参数

  1. 自然频率ωn​：无阻尼时的振荡频率
  2. 阻尼频率ωd​：阻尼振荡频率 ωd​=ωn​1−ζ2​
  3. 衰减系数σ：特征根的实部绝对值 σ=ζωn​
  4. 阻尼角β： β=arctan(ζ1−ζ2​​)=arccos(ζ)

极点与物理参数的几何关系

对于欠阻尼系统（0<ζ<1）：

  • 极点位置：s=−σ±jωd​
  • 几何关系：
    • 极点到原点的距离：ωn​
    • 极点与负实轴的夹角：β
    • 极点的实部：−σ=−ζωn​
    • 极点的虚部：±ωd​=±ωn​1−ζ2​

二阶系统性能指标公式

欠阻尼系统（0<ζ<1）

r$**：

tr​=ωd​π−β​=ωn​1−ζ2​π−arccos(ζ)​

  1. 峰值时间 tp​：

    tp​=ωd​π​=ωn​1−ζ2​π​

  2. 超调量 σ%：

    σ%=e−1−ζ2​ζπ​×100%=e−ωd​σπ​×100%

  3. 调节时间 ts​：

    • ±5%误差带：ts​≈ζωn​3​=σ3​
    • ±2%误差带：ts​≈ζωn​4​=σ4​

过阻尼系统（ζ>1）

过阻尼系统没有峰值时间和超调量，性能主要由调节时间和上升时间描述。

当两个实根比值大于4时（∣s2​∣>4∣s1​∣），快衰减模态占比小于20%，可近似为一阶系统：

ts​≈∣s1​∣3​,tr​≈∣s1​∣2.2​

其中s1​是离虚轴较近的极点（模值较小）。

临界阻尼系统（ζ=1）

临界阻尼系统也没有超调量，是最快的无超调响应：

ts​≈ωn​4.75​,tr​≈ωn​3.89​

性能指标与物理参数的关系

  1. 峰值时间：仅与阻尼频率ωd​有关
  2. 超调量：仅与阻尼比ζ有关
  3. 调节时间：主要取决于衰减系数σ=ζωn​
  4. 上升时间：主要取决于阻尼频率ωd​

设计权衡

  1. 快速性与平稳性的矛盾：

    • 减小tr​和ts​需要增大ωn​
    • 减小σ%需要增大ζ
    • 最佳折衷：ζ=0.707（此时σ%≈4.3%）

  2. 工程经验：

    • 系统的最佳阻尼比为0.707，兼顾快速性与小超调
    • 当ζ=0.707时，β=45°

3.4.4 额外极点/零点对系统响应的影响

额外极点的影响

在原有系统基础上串联一个一阶惯性环节：

Gnew​(s)=G(s)⋅Ts+11​
5倍经验法则

当额外极点的模值比主导极点大5倍以上时：

  1. 额外极点对应模态的系数与不考虑该极点时的差异在25%以内
  2. 在分析和设计时允许忽略该极点
  3. 但需要通过试验验证

物理意义：当极点A比极点B大5倍以上，则极点B所对应模态的系数与不考虑极点A时的差异在25%以内。

额外零点的影响

在原有系统基础上增加一个零点：

Gnew​(s)=G(s)⋅(s+z)

零点位置的影响

  1. 左半平面零点（z>0）：

    • 相当于构建了原系统的微分系统
    • 系统输出为两个系统的并联
    • 与原系统输出变化率成正比，加剧了变化程度
    • 使响应更快，但可能增加超调

  2. 右半平面零点（z<0）：

    • 非最小相位系统
    • 与原系统输出变化率成反比，与原系统"对着干"
    • 可能导致响应初期反向

零点对暂态响应的影响规律

  • 零点越靠近虚轴，影响越大
  • 左半平面零点使响应加速，可能增加超调
  • 右半平面零点可能导致非最小相位特性

3.4.5 高阶系统的近似分析

高阶系统的瞬态响应特性

高阶系统的瞬态响应是由一些一阶惯性环节和二阶振荡环节的响应函数叠加组成。

主导极点概念

主导极点：距虚轴最近的闭环极点。主导极点对系统响应起主要作用。

判断条件：当其他极点与主导极点的实部之比大于5时，可忽略非主导极点的影响。

偶极子概念

偶极子：某极点与对应零点之间的间距小于它们本身到原点距离的1/10时，即可认为是偶极子。

特性：

  1. 偶极子相消仅针对左半平面
  2. 右半平面的偶极子不能相消
  3. 偶极子对系统响应影响很小，可忽略

高阶系统降阶分析方法

  1. 识别主导极点：找到距虚轴最近的极点
  2. 检查非主导极点：应用5倍经验法则
  3. 检查偶极子：识别并处理偶极子
  4. 验证降阶结果：通过仿真验证降阶系统的准确性

工程经验

尽管可以降阶分析，但是还是要在原系统验证。设计人员的经验对于工程实践具有重要指导作用。

3.4.6 PID控制原理与应用

PID控制器的一般形式

PID控制器的传递函数为：

K(s)=Kp​+sKi​​+Kd​s

其中：

  • Kp​：比例增益
  • Ki​：积分增益
  • Kd​：微分增益

各控制环节的作用

1. 比例环节（P）
  • 对稳定性的影响：比例增益存在稳定下限
  • 对稳态误差的影响：比例增益越大，稳态误差越小
  • 对动态性能的影响：
    • 与自然频率ωn​正相关：增大Kp​提高ωn​
    • 不影响衰减系数σ，即不影响调节时间
    • 增大Kp​降低阻尼比ζ，提高阻尼频率ωd​
    • 使系统由过阻尼向欠阻尼变化，峰值时间降低，超调量增加
2. 微分环节（D）
  • 对稳定性的影响：微分增益存在稳定下限
  • 对稳态误差的影响：微分增益不影响稳态误差
  • 对动态性能的影响：
    • 与衰减系数σ的大小正相关：增大Kd​提高σ
    • 不影响自然频率ωn​
    • 与比例增益共同影响阻尼比ζ
    • 相当于引入额外的零点
3. 积分环节（I）
  • 对稳定性的影响：积分增益存在稳定上限，过大会引起系统失稳
  • 对稳态误差的影响：
    • 积分环节提高了系统型别
    • 积分增益越大，对应激励信号的稳态误差越小
  • 对动态性能的影响：
    • 增加了系统的阶数
    • 引入了额外的极点与零点

PID控制器的设计考虑

稳定性约束

对于典型二阶系统G(s)=s2+a1​s+a0​1​：

  1. 比例控制：

    • 特征方程：s2+a1​s+(a0​+Kp​)=0
    • 稳定条件：a1​>0，a0​+Kp​>0

  2. 比例-微分控制：

    • 特征方程：s2+(a1​+Kd​)s+(a0​+Kp​)=0
    • 稳定条件：a1​+Kd​>0，a0​+Kp​>0

  3. 比例-积分控制：

    • 特征方程：s3+a1​s2+(a0​+Kp​)s+Ki​=0
    • 稳定条件：劳斯判据确定Kp​和Ki​范围

  4. 比例-积分-微分控制：

    • 特征方程：s3+(a1​+Kd​)s2+(a0​+Kp​)s+Ki​=0
    • 稳定条件：劳斯判据确定Kp​、Ki​、Kd​范围

PID控制对系统性能的校正能力

  1. 比例控制：

    • 可以校正稳态误差
    • 无法校正响应速度
    • 过高的比例增益会引起较大的超调

  2. 比例-微分控制：

    • 可以校正稳态误差及响应速度
    • 相当于引入额外的零点

  3. 比例-积分控制：

    • 可以消除稳态误差（阶跃）/提高系统型别
    • 积分环节增加了系统的阶数

  4. 比例-积分-微分控制：

    • 可以视作比例-积分控制与比例-微分控制的并联
    • 综合改善系统行为

工程最佳参数

最佳阻尼比：ζ=0.707

  • 此时超调量σ%≈4.3%
  • 兼顾快速性与小超调
  • 阻尼角β=45°

3.4.8 小结与总结

核心概念总结

一阶系统

  1. 时间常数T：决定系统响应速度的关键参数
  2. 性能指标：ts​=3T（5%）/4T（2%），tr​=2.2T
  3. 特点：无超调，响应形状相似

二阶系统

  1. 自然频率ωn​：无阻尼振荡频率
  2. 阻尼比ζ：衰减与振荡的比值，决定系统类型
  3. 阻尼频率ωd​：实际振荡频率
  4. 衰减系数σ：特征根实部绝对值
  5. 阻尼角β：β=arccos(ζ)

系统类型

  1. 无阻尼：ζ=0，纯振荡
  2. 欠阻尼：0<ζ<1，衰减振荡
  3. 临界阻尼：ζ=1，最快无超调
  4. 过阻尼：ζ>1，缓慢无超调

性能指标公式（欠阻尼）

  1. tr​=ωd​π−β​
  2. tp​=ωd​π​
  3. σ%=e−1−ζ2​ζπ​×100%
  4. ts​≈ζωn​3​（5%）/ζωn​4​（2%）

重要方法总结

系统分析步骤

  1. 确定系统传递函数
  2. 计算自然频率ωn​和阻尼比ζ
  3. 判断系统类型
  4. 根据类型选择相应公式计算性能指标
  5. 分析额外极点和零点的影响

高阶系统近似方法

  1. 主导极点法：5倍经验法则
  2. 偶极子相消：间距小于1/10距离
  3. 验证：在原系统验证降阶结果

PID控制器设计

  1. 比例环节：影响稳态误差和自然频率
  2. 微分环节：影响衰减系数和阻尼比
  3. 积分环节：提高系统型别，消除稳态误差
  4. 稳定性约束：各增益存在上下限

设计权衡与工程考虑

性能指标之间的矛盾

  1. 快速性与平稳性：减小tr​和ts​需要增大ωn​，减小σ%需要增大ζ
  2. 稳定性与精度：提高增益减小误差，但可能降低稳定性
  3. 响应速度与鲁棒性：快速响应系统对参数变化更敏感

工程最佳参数

  1. 最佳阻尼比：ζ=0.707
  2. 超调量：σ%≈4.3%
  3. 设计目标：兼顾快速性与小超调

经验法则

  1. 5倍经验：额外极点模值大于主导极点5倍时可忽略
  2. 偶极子：极零点间距小于1/10距离时可相消
  3. 过阻尼近似：实根比值大于4时可近似为一阶系统

关键公式回顾

一阶系统

  • 传递函数：G(s)=Ts+1K​
  • 阶跃响应：y(t)=K(1−e−t/T)
  • 性能指标：ts​=3T/4T，tr​=2.2T

二阶系统

  • 标准形式：G(s)=s2+2ζωn​s+ωn2​ωn2​​
  • 特征根：s1,2​=−ζωn​±ωn​ζ2−1​
  • 阻尼频率：ωd​=ωn​1−ζ2​
  • 衰减系数：σ=ζωn​
  • 阻尼角：β=arccos(ζ)

性能指标

  • tr​=ωd​π−β​
  • tp​=ωd​π​
  • σ%=e−1−ζ2​ζπ​×100%
  • ts​≈ζωn​3​（5%）/ζωn​4​（2%）

工程应用价值

  1. 系统设计：根据性能要求确定系统结构和参数
  2. 控制器整定：调整PID参数满足性能指标
  3. 性能评估：分析现有系统的稳态和动态性能
  4. 系统改进：识别性能瓶颈并采取改进措施
  5. 鲁棒性分析：分析参数变化对性能的影响

常见错误与注意事项

  1. 公式适用条件：性能指标公式仅适用于特定类型系统
  2. 稳定性前提：所有分析基于稳定系统
  3. 近似条件：5倍经验和偶极子相消需要验证
  4. 设计矛盾：注意稳定性、精度、快速性、平稳性之间的矛盾
  5. 参数单位：注意时间单位的一致性（秒、毫秒等）
  6. 系统类型判断：正确识别积分环节个数和阻尼比
  7. PID参数整定：各增益存在相互影响，需要综合考虑

  3. 理解物理意义：不仅记住公式，更要理解参数的物理意义
  4. 工程思维：培养工程实践中的权衡和折衷思维
  5. 系统思维：从整体角度理解各环节的相互影响
